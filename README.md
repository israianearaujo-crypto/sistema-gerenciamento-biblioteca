# Sistema de Gerenciamento de Biblioteca

## Objetivo
O Sistema de Gerenciamento de Biblioteca tem como objetivo facilitar o cadastro, a pesquisa, o empréstimo, a devolução e a reserva de livros, além de permitir o acompanhamento do histórico de empréstimos dos usuários.

## Principais funcionalidades
- Cadastro de livros;
- Cadastro de usuários;
- Pesquisa de livros por título, autor ou ISBN;
- Consulta da disponibilidade dos livros;
- Reserva de livros;
- Registro de empréstimos e devoluções;
- Consulta do histórico de empréstimos;
- Envio de notificações sobre o prazo de devolução;
- Geração de relatórios dos livros mais emprestados.
